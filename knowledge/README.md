# knowledge/

Plain markdown rules that the bot injects into every Devin session prompt. Everything here is
version-controlled and human-reviewed: change a rule with a pull request, not in a chat.

- `triage-and-fix.md`: gotchas about the target repository that prevent blocked / failed sessions.
- Later milestones: `scan.md` (what the sweep looks for) and rules proposed by the `learn` command
  (as one batched PR labeled `devin:knowledge-base-improvement`).

This README is not sent to Devin.
